# Assessment Studio

IB MYP practice tests generated by Gemini. Static site in `public/`, one Netlify Function in `netlify/functions/api.mjs`.

## Netlify environment variables

Set these in Project configuration → Environment variables, then redeploy.

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| `GEMINI_API_KEY` | yes | | Gemini key from Google AI Studio. Only the function reads it. |
| `GEMINI_MODEL` | no | `gemini-3.5-flash-lite` | Model tried first. |
| `GEMINI_FALLBACK_MODELS` | no | `gemini-3.8-flash` | Comma-separated models tried in order when the first one is busy, rate-limited or fails. |
| `ASSESSMENT_AI_ENABLED` | no | `true` | Set to `false` to switch generation and review off for everyone. |

## API

- `POST /api/generate` returns `{ questions, modelUsed }`.
- `POST /api/review` marks written answers and returns `{ results, modelUsed }`. Multiple-choice, multi-select and true/false questions are marked in the browser.

Both endpoints ask Gemini for JSON that matches a fixed schema, so LaTeX in questions and feedback cannot break parsing.
